# Birdmen + Basra 全地形小车无线串口版

## 当前方案：手机蓝牙遥控

遥控端已升级为**手机 + HC-05 蓝牙**，不再使用 Arduino 手柄。主车端 `slave.ino` 无需修改。

详细配置指南：[docs/bluetooth-setup.md](docs/bluetooth-setup.md)

---

## 1. 文件

| 文件 | 作用 |
|---|---|
| `slave/slave.ino` | Basra 主车端，串口接收指令，控制电机、机械臂、机械爪和 D12 新舵机 |
| `docs/bluetooth-setup.md` | 手机蓝牙遥控配置指南（配对、APP、按钮映射） |
| `motor_test/motor_test.ino` | 不接无线时单独测试 D5/D6/D9/D10 电机方向 |
| `servo_test/servo_test.ino` | 不接无线时单独测试 D3/D7/D8 舵机方向和角度 |
| `gripper_test/gripper_test.ino` | 不接无线时单独测试 D8 夹爪开合 |
| `aux_servo_test/aux_servo_test.ino` | 不接无线时单独测试 D12 新舵机动作 |
| `master/master.ino` | ~~已归档~~ 原 Arduino 遥控端，保留作为参考（见 `master/ARCHIVE.md`） |

## 2. 主车电机引脚

| 功能 | 引脚 |
|---|---|
| IN1 | D5 |
| IN2 | D6 |
| IN3 | D9 |
| IN4 | D10 |

动作逻辑：

| 指令 | 动作 | IN1 | IN2 | IN3 | IN4 |
|---|---|---|---|---|---|
| 1 | 前进 | HIGH | LOW | HIGH | LOW |
| 2 | 后退 | LOW | HIGH | LOW | HIGH |
| 3 | 停止 | LOW | LOW | LOW | LOW |
| 4 | 左转 | LOW | HIGH | HIGH | LOW |
| 5 | 右转 | HIGH | LOW | LOW | HIGH |

如果实际方向相反，优先交换电机输出线，或在 `slave.ino` 里改对应函数。

## 3. 主车舵机和夹爪引脚

| 功能 | 引脚 | 角度范围 | 说明 |
|---|---|---|---|
| 大舵机 A | D3 | 45~135 度 | 与大舵机 B 同步 |
| 大舵机 B | D7 | 45~135 度 | 与大舵机 A 同步 |
| 机械爪舵机 | D8 | 0~120 度 | 手机 APP 按钮或 G 指令控制 |
| 新舵机 | D12 | 0~180 度 | 初始 100 度，手机 APP 按钮或 A 指令控制 |

大舵机默认 90 度居中。D12 新舵机初始为 100 度，通过手机 APP 发送指令控制角度，不自动复位。

注意：Arduino UNO 使用 `Servo` 库后会占用 Timer1，D9/D10 的 PWM 会受影响。本程序里 D9/D10 只用 `digitalWrite` 做电机方向控制，不使用 PWM，所以可以和 Servo 库一起工作。

## 4. 蓝牙模块接线

HC-05/HC-06 蓝牙模块接到 Basra，接法与原无线串口模块**完全一样**：

| Basra | HC-05/HC-06 |
|---|---|
| D1/TX | RX |
| D0/RX | TX |
| GND | GND |
| VCC | VCC |

注意：

- 上传程序时，D0/D1 上接着蓝牙模块会导致上传失败；先拔掉模块，上传后再插回。
- HC-05 默认波特率 9600，与 `slave.ino` 一致，无需修改。
- D12 已用于新舵机，蓝牙模块不占用 D12。

## 5. 手机遥控输入

使用 Bluetooth Serial Controller 等 APP，按钮绑定发送字符串：

| APP 按钮 | 发送内容 | 功能 |
|---|---|---|
| 前进 | `1` | 小车前进 |
| 后退 | `2` | 小车后退 |
| 停止 | `3` | 小车停止 |
| 左转 | `4` | 小车左转 |
| 右转 | `5` | 小车右转 |
| 爪开 | `G120` | 夹爪张开到 120° |
| 爪合 | `G0` | 夹爪闭合到 0° |
| 辅+ | `A110` | D12 舵机 110° |
| 辅- | `A90` | D12 舵机 90° |

也可以发送组合指令同时控制多个部件，例如 `1,90,60,100`。详见 [docs/bluetooth-setup.md](docs/bluetooth-setup.md)。

## 6. 通信格式

新格式仍然保留原始动作码在第一位：

```text
行走指令,机械臂角度,机械爪角度,新舵机角度
```

示例：

```text
1,90,60,100
3,120,100,110
```

字段说明：

| 字段 | 范围 | 说明 |
|---|---|---|
| 行走指令 | 1~5 | 1前进，2后退，3停止，4左转，5右转 |
| 机械臂角度 | 45~135 | 两个大舵机同步输出 |
| 机械爪角度 | 0~120 | D8 机械爪连续角度 |
| 新舵机角度 | 0~180 | D12 新舵机，初始100，按键步进后保持 |

主车端仍兼容旧格式。只收到单个 `1~5` 时，只更新电机动作，不改舵机和机械爪。

主车端还支持夹爪调试快捷指令：

```text
G120
G0
A110
A90
```

`G角度` 表示设置 D8 机械爪角度，`A角度` 表示设置 D12 新舵机角度。可以通过串口透传模块发送，也可以在临时调试时用串口监视器发送。

## 7. 分步骤调试

### 第一步：只测电机

1. 不接无线模块。
2. 打开 `motor_test/motor_test.ino`。
3. 上传到主车 Basra。
4. 小车会依次执行前进、后退、左转、右转。
5. 先把电机方向调正确。

### 第二步：只测舵机和夹爪

1. 不接无线模块。
2. 打开 `servo_test/servo_test.ino`。
3. 上传到主车 Basra。
4. D3/D7 两个大舵机会依次走 45、90、135、90 度。
5. 夹爪会依次张开到 60 度，再闭合到 0 度。
6. 如果机械方向相反，先调整舵机安装方向；必要时再对调 `ARM_MIN_ANGLE` 和 `ARM_MAX_ANGLE` 的映射逻辑。

### 第三步：只测夹爪

1. 不接无线模块。
2. 打开 `gripper_test/gripper_test.ino`。
3. 上传到主车 Basra。
4. D8 夹爪舵机会在 0 度和 60 度之间反复切换。
5. 如果夹爪完全不动，检查舵机 5V 供电和 GND 共地。
6. 如果方向反了或开合不够，修改 `GRIPPER_CLOSE` 和 `GRIPPER_OPEN`。

### 第四步：只测 D12 新舵机

1. 不接无线模块。
2. 打开 `aux_servo_test/aux_servo_test.ino`。
3. 上传到主车 Basra。
4. D12 新舵机会依次到 110、100、90、100 度。
5. 如果方向和要求相反，交换 `AUX_CW_STEP` 和 `AUX_CCW_STEP` 的值。

### 第五步：上传主车端

1. 打开 `slave/slave.ino`。
2. 拔掉 HC-05 蓝牙模块。
3. 上传到主车 Basra。
4. 上传完成后插回 HC-05。

### 第六步：蓝牙配对

1. HC-05 上电，LED 快闪（等待配对）。
2. 手机蓝牙设置 → 搜索设备 → 配对 HC-05（密码 `1234`）。
3. 配对成功后 LED 慢闪。

### 第七步：手机联调

1. 打开 Bluetooth Serial Controller → 连接 HC-05。
2. 按"停止"按钮（发送 `3`），确认主车不动。
3. 按"前进"按钮（发送 `1`），主车应前进。
4. 按"停止"按钮，主车应停止。
5. 按"爪开"按钮（发送 `G120`），夹爪应张开。
6. 按"辅+"按钮（发送 `A110`），D12 舵机应转动。
7. 关闭手机蓝牙，500ms 后主车应自动停止。

## 8. 安全保护

主车端新增 500ms 超时停车：

- 500ms 内没有收到 `1~5`，自动执行停止。
- 避免旧源码里“无线断开后继续跑上一个动作”的问题。
- 超时只停车，舵机、机械爪和新舵机保持最后一次位置，防止机械机构突然掉位。

## 9. 常见问题

- 连不上 HC-05：先在手机蓝牙设置里配对（密码 1234），再在 APP 里连接。
- 发指令没反应：确认 HC-05 波特率为 9600，与 `slave.ino` 一致。
- 一上传就失败：先拔掉 D0/D1 上的蓝牙模块。
- 方向反了：先测 `motor_test`，再改 `slave.ino` 的 `forward/backward/left/right`。
- 蓝牙延迟大：关闭重连，或重启手机蓝牙。
- 舵机抖动：给舵机单独 5V 供电，舵机电源 GND 必须和 Basra GND 共地。
- 夹爪角度不够或过大：修改 `GRIPPER_CLOSE` 和 `GRIPPER_OPEN`，先小范围测试。
