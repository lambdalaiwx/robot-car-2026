# Basra 全车接线图

## Basra (Arduino UNO) 引脚总览

```
            Basra / Arduino UNO
           ┌──────────────────┐
           │                  │
      D0 ──┤ RX          A0 ──┤── 状态LED（可选）
      D1 ──┤ TX          A1 ──┤── (空)
      D2 ──┤             A2 ──┤── (空)
      D3 ──┤ 舵机A       A3 ──┤── (空)
      D4 ──┤             A4 ──┤── (空)
      D5 ──┤ 电机IN1     A5 ──┤── (空)
      D6 ──┤ 电机IN2          │
      D7 ──┤ 舵机B            │
      D8 ──┤ 夹爪舵机         │
      D9 ──┤ 电机IN3          │
     D10 ──┤ 电机IN4          │
     D11 ──┤ (空)             │
     D12 ──┤ 新舵机           │
     D13 ──┤ (板载LED)        │
     GND ──┤ GND              │
      5V ──┤ 5V               │
           └──────────────────┘
```

## 1. 蓝牙模块 (HC-05/HC-06)

| Basra | HC-05/HC-06 | 说明 |
|-------|-------------|------|
| D1 (TX) | RX | Basra 发 → 蓝牙收 |
| D0 (RX) | TX | 蓝牙发 → Basra 收 |
| 5V | VCC | 供电 |
| GND | GND | 共地 |

## 2. 电机驱动 (L298N / 双H桥)

| Basra | 驱动板 | 功能 |
|-------|--------|------|
| D5 | IN1 | 左电机方向A |
| D6 | IN2 | 左电机方向B |
| D9 | IN3 | 右电机方向A |
| D10 | IN4 | 右电机方向B |
| (驱动板自带ENA/ENB跳线) | ENA/ENB | 默认使能，不用接PWM |

电机输出线如果方向反了，优先对调电机侧的两根线。

## 3. 机械臂舵机 x2

| Basra | 舵机 | 角度范围 |
|-------|------|----------|
| D3 | 大舵机 A（信号线） | 45° ~ 135° |
| D7 | 大舵机 B（信号线） | 45° ~ 135° |
| 5V 或外部5V | 两舵机 VCC（红线） | 供电 |
| GND | 两舵机 GND（棕线） | 共地 |

两个舵机同步转动，默认居中 90°。

## 4. 夹爪舵机

| Basra | 舵机 | 角度范围 |
|-------|------|----------|
| D8 | 夹爪舵机（信号线） | 0°（闭合）~ 120°（张开） |
| 5V 或外部5V | VCC（红线） | 供电 |
| GND | GND（棕线） | 共地 |

## 5. 新舵机 (D12)

| Basra | 舵机 | 角度范围 |
|-------|------|----------|
| D12 | 新舵机（信号线） | 0° ~ 180°，初始 100° |
| 5V 或外部5V | VCC（红线） | 供电 |
| GND | GND（棕线） | 共地 |

## 6. 状态LED（可选）

| Basra | LED | 功能 |
|-------|-----|------|
| A0 | LED + 限流电阻 → GND | 行驶时亮，停止时灭 |

## 供电方案

```
电池/电源
  ├── 驱动板 VCC → 驱动板供电（7~12V）
  │       └── 驱动板 5V 输出 → Basra VIN（或 Basra USB供电）
  │
  └── 舵机供电（推荐外部5V）
          ├── 舵机A VCC
          ├── 舵机B VCC
          ├── 夹爪舵机 VCC
          ├── 新舵机 VCC
          └── GND ──→ Basra GND（必须共地！）
```

**重要：**
- 4个舵机同时工作电流较大（每个 100~500mA），建议用**外部 5V 电源**单独供电，不要走 Basra 的 5V 引脚
- 外部电源 GND **必须**和 Basra GND 连在一起（共地），否则舵机会抖动或不响应
- HC-05 蓝牙模块功耗低，可以接 Basra 5V

## 接线顺序建议

1. 先接电机驱动板 → 测 `motor_test.ino`
2. 再接 4 个舵机 → 测 `servo_test.ino`、`gripper_test.ino`、`aux_servo_test.ino`
3. 最后接 HC-05 蓝牙模块 → 手机配对联调
4. 每一步确认方向正确再接下一步
