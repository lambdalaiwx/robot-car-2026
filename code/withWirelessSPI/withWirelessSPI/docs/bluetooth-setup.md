# 手机蓝牙遥控配置指南

## 硬件准备

| 部件 | 说明 |
|------|------|
| HC-05 或 HC-06 | 蓝牙串口透传模块，替换原无线串口模块 |
| Android 手机 | 需支持蓝牙 SPP（几乎所有 Android 都支持） |
| Basra 主车 | 运行 `slave/slave.ino`，无需修改 |

## 接线

HC-05/HC-06 接到 Basra，与原无线模块接法**完全一样**：

| Basra | HC-05/HC-06 |
|-------|-------------|
| D1 (TX) | RX |
| D0 (RX) | TX |
| 5V | VCC |
| GND | GND |

注意：上传程序时**必须先拔掉 HC-05 模块**，否则 D0/D1 被占用会导致上传失败。

## 蓝牙配对

1. HC-05 上电后 LED 快速闪烁 = 等待配对
2. 手机蓝牙设置 → 搜索设备 → 找到 HC-05
3. 输入配对密码：`1234`（HC-05 默认）或 `0000`（HC-06 默认）
4. 配对成功后 LED 慢闪

## 推荐 APP

### 方案 A：Bluetooth Serial Controller（推荐）

Google Play 搜索 "Bluetooth Serial Controller"，安装后配置：

1. 打开 APP → 连接 → 选择已配对的 HC-05
2. 长按按钮 → 设置发送字符串

**按钮配置表：**

| 按钮标签 | 发送内容 | 功能 |
|----------|----------|------|
| 前进 | `1` | 小车前进 |
| 后退 | `2` | 小车后退 |
| 左转 | `4` | 小车左转 |
| 右转 | `5` | 小车右转 |
| 停止 | `3` | 小车停止 |
| 臂抬 | `3,135,60,100` | 停车 + 机械臂抬到 135° |
| 臂降 | `3,45,60,100` | 停车 + 机械臂降到 45° |
| 臂中 | `3,90,60,100` | 停车 + 机械臂回到 90° |
| 爪开 | `G120` | 夹爪张开到 120° |
| 爪合 | `G0` | 夹爪闭合到 0° |
| 爪半 | `G60` | 夹爪半开 60° |
| 辅+ | `A110` | D12 舵机转到 110° |
| 辅- | `A90` | D12 舵机转到 90° |
| 辅中 | `A100` | D12 舵机回到初始 100° |

**组合指令（同时控制多个部件）：**

| 发送内容 | 含义 |
|----------|------|
| `1,90,60,100` | 前进 + 臂90° + 爪60° + 辅助100° |
| `3,120,0,110` | 停止 + 臂120° + 爪合 + 辅助110° |
| `4,90,120,100` | 左转 + 臂90° + 爪开 + 辅助100° |

### 方案 B：Serial Bluetooth Terminal

适合调试阶段。手动输入字符串发送，可以验证通信是否正常。

1. 连接 HC-05
2. 输入 `1` 发送 → 小车前进
3. 输入 `3` 发送 → 小车停止
4. 输入 `1,90,60,100` 发送 → 组合指令

## 通信格式速查

```
行走指令,机械臂角度,机械爪角度,新舵机角度

行走指令: 1前进 2后退 3停止 4左转 5右转
机械臂:   45~135度 (D3/D7 同步)
机械爪:   0~120度  (D8)
新舵机:   0~180度  (D12, 初始100)

快捷指令:
  G<角度>  设置夹爪角度  例: G120
  A<角度>  设置新舵机角度 例: A90
```

## 安全保护

- 500ms 无数据自动停车（蓝牙断开后生效）
- 超时只停车，舵机保持最后位置
- 蓝牙延迟约 50-100ms，对小车操控无明显影响

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 连不上 HC-05 | 没配对 | 先在手机蓝牙设置里配对 |
| 发指令没反应 | 波特率不对 | 确认 HC-05 波特率为 9600 |
| 上传程序失败 | HC-05 占用 D0/D1 | 先拔掉模块，上传后再插回 |
| 蓝牙连上但延迟大 | 手机蓝牙缓存 | 关闭重连，或重启手机蓝牙 |
| 电机方向反了 | 接线反了 | 交换电机输出线，或改 slave.ino 的方向函数 |
