# 操作手册

## 一、烧录

| 文件 | 烧到 | 注意事项 |
|------|------|----------|
| `master/master.ino` | 遥控器 Arduino | 烧录前拔掉无线串口模块 |
| `slave/slave.ino` | 小车 Arduino | 烧录前拔掉无线串口模块 |

Slave 端需要安装 Arduino 库：**U8x8lib**

## 三、遥控操作

### 摇杆（始终生效）

| 操作 | 控制对象 | 说明 |
|------|----------|------|
| 左摇杆 前推 | 前进 | A0 > 680 |
| 左摇杆 后拉 | 后退 | A0 < 340 |
| 左摇杆 左拨 | 左转 | A1 < 340 |
| 左摇杆 右拨 | 右转 | A1 > 680 |
| 右摇杆 Y 上推 | 关节3 角度增大（抬臂） | |
| 右摇杆 Y 下拉 | 关节3 角度减小（降臂） | |
| 右摇杆 X 左拨 | 夹爪张开（角度增大） | |
| 右摇杆 X 右拨 | 夹爪闭合（角度减小） | |

### 按钮（模式相关）

| 操作 | 效果 |
|------|------|
| **S1 短按** | 当前模式舵机 **+10°** |
| **S1 双击**（350ms 内连按两次） | **切换模式** |
| **S2 短按** | 当前模式舵机 **-10°** |

### 模式切换顺序

```
模式0: 关节1(D3) → 按S1双击 → 模式1: 关节2(D4) → 按S1双击 → 模式2: 越障(D7) → 按S1双击 → 循环回模式0
```

| 模式 | 控制对象 | 量程 | 初始值 | 串口提示 |
|------|----------|------|--------|----------|
| 0 | 关节1 (D3) | 75°~180° | 120° | `Mode: Joint1` |
| 1 | 关节2 (D4) | 15°~160° | 30° | `Mode: Joint2` |
| 2 | 越障 (D7) | 0°~180° | 90° | `Mode: Obstacle` |

## 四、舵机总览

| 舵机 | 引脚 | 量程 | 初始值 | 遥控方式 |
|------|------|------|--------|----------|
| 夹爪 | D12 | 30°(夹紧) ~ 90°(放松) | 90° | 右摇杆 X |
| 关节3 | D8 | 10°(往下) ~ 170°(往上) | 80° | 右摇杆 Y |
| 关节2 | D4 | 15°(往里) ~ 160°(往外) | 30° | S1/S2（模式1） |
| 关节1 | D3 | 75°(往里) ~ 180°(往外) | 120° | S1/S2（模式0） |
| 越障 | D7 | 0° ~ 180° | 90° | S1/S2（模式2） |

## 五、通信协议

Master 每 50ms 发送一帧 CSV，格式：

```
cmd,joint1,joint2,joint3,gripper,obstacle
```

| 字段 | 范围 | 示例 |
|------|------|------|
| cmd（行驶） | 1~5 | `3` |
| joint1（关节1） | 75~180 | `120` |
| joint2（关节2） | 15~160 | `30` |
| joint3（关节3） | 10~170 | `80` |
| gripper（夹爪） | 30~90 | `90` |
| obstacle（越障） | 0~180 | `90` |

帧示例：`3,120,30,80,90,90`

### cmd 行驶命令

| 值 | 含义 |
|----|------|
| 1 | 前进 |
| 2 | 后退 |
| 3 | 停止 |
| 4 | 左转 |
| 5 | 右转 |

## 六、Slave 调试命令

通过串口直接发送，用于单独测试舵机：

| 命令 | 效果 | 示例 |
|------|------|------|
| `G<角度>` | 设置夹爪角度 | `G60` |
| `O<角度>` | 设置越障角度 | `O45` |

## 七、OLED 显示

- 型号：SH1106 128x64 I2C
- 初始显示：`Basra Ready`
- 接收 OpenMV 二维码数据时：
  - 收到 `SLOW`：显示 `SLOW Mode >`
  - 收到其他内容：停车，显示 `Target Found:` + 扫码结果
