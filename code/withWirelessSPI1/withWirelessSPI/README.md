# Birdmen + Basra 全地形小车无线串口版

这版按原 `withWireless/master.abp` 和 `withWireless/slave.abp` 的源码逻辑重做，不再使用 Mirf/SPI 通信库。

原源码通信模型是：

- master：`Serial.println(1~5)`
- slave：`Serial.read()` 接收 `1~5`

也就是说，无线模块按“串口透传模块”使用，Arduino 代码只负责串口收发。

## 1. 文件

| 文件 | 作用 |
|---|---|
| `master/master.ino` | Birdmen 遥控端，读摇杆和按键，串口发送行走、机械臂、机械爪、新舵机指令 |
| `slave/slave.ino` | Basra 主车端，串口接收指令，控制电机、机械臂、机械爪和 D12 新舵机 |
| `motor_test/motor_test.ino` | 不接无线时单独测试 D5/D6/D9/D10 电机方向 |
| `servo_test/servo_test.ino` | 不接无线时单独测试 D3/D7/D8 舵机方向和角度 |
| `gripper_test/gripper_test.ino` | 不接无线时单独测试 D8 夹爪开合 |
| `aux_servo_test/aux_servo_test.ino` | 不接无线时单独测试 D12 新舵机动作 |

## 2. 主车电机引脚

| 功能 | 引脚 |
|---|---|
| IN1 | D5 |
| IN2 | D6 |
| IN3 | D9 |
| IN4 | D10 |

动作逻辑：

| 指令 | 动作 | IN1 | IN2 | IN3 | IN4 |
|---|---|---|---|---|---|
| 1 | 前进 | HIGH | LOW | HIGH | LOW |
| 2 | 后退 | LOW | HIGH | LOW | HIGH |
| 3 | 停止 | LOW | LOW | LOW | LOW |
| 4 | 左转 | LOW | HIGH | HIGH | LOW |
| 5 | 右转 | HIGH | LOW | LOW | HIGH |

如果实际方向相反，优先交换电机输出线，或在 `slave.ino` 里改对应函数。

## 3. 主车舵机和夹爪引脚

| 功能 | 引脚 | 角度范围 | 说明 |
|---|---|---|---|
| 大舵机 A | D3 | 45~135 度 | 与大舵机 B 同步 |
| 大舵机 B | D7 | 45~135 度 | 与大舵机 A 同步 |
| 机械爪舵机 | D8 | 0~120 度 | 右摇杆 X 连续控制 |
| 新舵机 | D12 | 0~180 度 | 初始 100 度，S1 每按一次 +10 度，S2 每按一次 -10 度 |

按照新控制逻辑，大舵机默认 90 度居中；右摇杆 Y 控制机械臂前伸/后缩，右摇杆 X 控制机械爪开合。D12 新舵机初始为 100 度；S1 每按下一次顺时针增加 10 度，S2 每按下一次逆时针减少 10 度，松开后保持当前位置，不复位。

注意：Arduino UNO 使用 `Servo` 库后会占用 Timer1，D9/D10 的 PWM 会受影响。本程序里 D9/D10 只用 `digitalWrite` 做电机方向控制，不使用 PWM，所以可以和 Servo 库一起工作。

## 4. 无线串口接线

遥控端和主车端都按串口透传接：

| Arduino/Basra | 无线串口模块 |
|---|---|
| D1/TX | RX |
| D0/RX | TX |
| GND | GND |
| VCC | VCC |

注意：

- 上传程序时，D0/D1 上接着无线模块可能导致上传失败；失败就先拔掉模块，上传后再插回。
- 这版程序不使用 SPI 无线通信。
- D12 已用于新舵机。如果你的无线模块底板硬件仍然占着 D12，请不要同时接新舵机，需要重新分配接口。

## 5. 遥控端输入

| Birdmen 输入 | Arduino 引脚 | 作用 |
|---|---|---|
| 摇杆 X | A0 | 左右转 |
| 摇杆 Y | A1 | 前进/后退 |
| 右摇杆 X | A2 | 机械爪角度 0~120 度 |
| 右摇杆 Y | A3 | 机械臂角度 45~135 度，松开后保持当前位置 |
| S1 按键 | D2 | D12 新舵机顺时针 +10 度 |
| S2 按键 | D3 | D12 新舵机逆时针 -10 度 |
| LED | D7 | 非停止时亮 |
| LED | D8 | 停止时亮 |

摇杆判定区间：

- A1 > 680：发送 `1` 前进
- A1 < 340：发送 `2` 后退
- A0 < 340：发送 `4` 左转
- A0 > 680：发送 `5` 右转
- 其它情况：发送 `3` 停止

发送周期为 100ms，主车端把连续数据当作心跳。

## 6. 通信格式

新格式仍然保留原始动作码在第一位：

```text
行走指令,机械臂角度,机械爪角度,新舵机角度
```

示例：

```text
1,90,60,100
3,120,100,110
```

字段说明：

| 字段 | 范围 | 说明 |
|---|---|---|
| 行走指令 | 1~5 | 1前进，2后退，3停止，4左转，5右转 |
| 机械臂角度 | 45~135 | 两个大舵机同步输出 |
| 机械爪角度 | 0~120 | D8 机械爪连续角度 |
| 新舵机角度 | 0~180 | D12 新舵机，初始100，按键步进后保持 |

主车端仍兼容旧格式。只收到单个 `1~5` 时，只更新电机动作，不改舵机和机械爪。

主车端还支持夹爪调试快捷指令：

```text
G120
G0
A110
A90
```

`G角度` 表示设置 D8 机械爪角度，`A角度` 表示设置 D12 新舵机角度。可以通过串口透传模块发送，也可以在临时调试时用串口监视器发送。

## 7. 分步骤调试

### 第一步：只测电机

1. 不接无线模块。
2. 打开 `motor_test/motor_test.ino`。
3. 上传到主车 Basra。
4. 小车会依次执行前进、后退、左转、右转。
5. 先把电机方向调正确。

### 第二步：只测舵机和夹爪

1. 不接无线模块。
2. 打开 `servo_test/servo_test.ino`。
3. 上传到主车 Basra。
4. D3/D7 两个大舵机会依次走 45、90、135、90 度。
5. 夹爪会依次张开到 60 度，再闭合到 0 度。
6. 如果机械方向相反，先调整舵机安装方向；必要时再对调 `ARM_MIN_ANGLE` 和 `ARM_MAX_ANGLE` 的映射逻辑。

### 第三步：只测夹爪

1. 不接无线模块。
2. 打开 `gripper_test/gripper_test.ino`。
3. 上传到主车 Basra。
4. D8 夹爪舵机会在 0 度和 60 度之间反复切换。
5. 如果夹爪完全不动，检查舵机 5V 供电和 GND 共地。
6. 如果方向反了或开合不够，修改 `GRIPPER_CLOSE` 和 `GRIPPER_OPEN`。

### 第四步：只测 D12 新舵机

1. 不接无线模块。
2. 打开 `aux_servo_test/aux_servo_test.ino`。
3. 上传到主车 Basra。
4. D12 新舵机会依次到 110、100、90、100 度。
5. 如果方向和要求相反，交换 `AUX_CW_STEP` 和 `AUX_CCW_STEP` 的值。

### 第五步：上传遥控端

1. 打开 `master/master.ino`。
2. 选择 `Arduino/Genuino UNO`。
3. 上传到 Birdmen 遥控端。
4. 如上传失败，拔掉 D0/D1 上的无线模块再上传。

### 第六步：上传主车端

1. 打开 `slave/slave.ino`。
2. 上传到主车 Basra。
3. 接回无线串口模块。

### 第七步：无线联调

1. 遥控端和主车端同时上电。
2. 摇杆回中，主车应停止。
3. 前后推动 A1，主车前进或后退。
4. 左右推动 A0，主车左转或右转。
5. 推动右摇杆 Y，D3/D7 两个大舵机同步改变角度；松开后停留在最后角度。
6. 推动右摇杆 X，D8 机械爪改变开合角度。
7. 按一下 S1，D12 新舵机顺时针增加 10 度；按一下 S2，D12 新舵机逆时针减少 10 度；松开后保持当前位置。

## 8. 安全保护

主车端新增 500ms 超时停车：

- 500ms 内没有收到 `1~5`，自动执行停止。
- 避免旧源码里“无线断开后继续跑上一个动作”的问题。
- 超时只停车，舵机、机械爪和新舵机保持最后一次位置，防止机械机构突然掉位。

## 9. 常见问题

- 完全不动：检查两个无线模块波特率是否都是 9600。
- 一上传就失败：先拔掉 D0/D1 上的无线模块。
- 方向反了：先测 `motor_test`，再改 `slave.ino` 的 `forward/backward/left/right`。
- 摇杆方向反了：交换 `master.ino` 里 A0/A1 的判断，或调整高低阈值对应的命令。
- 舵机抖动：给舵机单独 5V 供电，舵机电源 GND 必须和 Basra GND 共地。
- 夹爪角度不够或过大：修改 `GRIPPER_CLOSE` 和 `GRIPPER_OPEN`，先小范围测试。
